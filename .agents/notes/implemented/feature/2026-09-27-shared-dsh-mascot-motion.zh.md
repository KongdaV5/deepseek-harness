# Agent Note: 共用 DSH 助手形象动画

Status: implemented

[English](2026-09-27-shared-dsh-mascot-motion.md) | 中文

## 问题

侧栏与空会话首页使用不同标记，导致 DSH 身份在相邻界面间变化，也无法一致地回应用户操作。若从按钮标签推断操作含义，行为还会受本地化文案影响。

## 决策

[`ui-primitives`](../../../../packages/client/ui-primitives/README.zh.md) 中的 `DshMascotMark` 是共用的 DSH 装饰性助手形象。官方品牌包、侧栏回退标记和空会话首页都会按宿主请求的尺寸渲染它。它拥有短暂的视觉状态和指针视线；不会读取或修改 Session 数据，也不会影响模型请求。

形象会回应输入框聚焦、输入、提交、指针活动，以及通过键盘或指针激活控件。需要触发特定反应的控件带有稳定的 `data-dsh-mascot-action` 值：`new-session`、`send` 或 `stop`；形象不会从本地化文案或无障碍标签推断操作含义。其他导航控件会触发好奇状态。

页面可见且用户未请求减少动态效果时，形象每隔随机 2.1–4.2 秒做一次待机动作。用户操作引发的反应持续 1.5 秒。页面隐藏或用户启用减少动态效果后，会停止排定后续动作；CSS 也会为减少动态效果的用户禁用形象和相关字标动画。

## 备选方案

**保留侧栏鱼形标记，首屏图形由会话包自己维护。**这样可以保留各界面彼此独立的图形与行为，但产品身份仍会在侧栏和新会话首页之间变化，而且每个界面都要各自维护一套图形。

**从可见文案或无障碍标签推断操作。**早期实现匹配了英文和中文标签。标签面向用户，可能随语言或文案调整而变化，因此实现改为从所属控件读取稳定的动作值。

## 后果

共用组件拥有短暂的交互状态和文档事件监听。需要触发特定心情的宿主控件必须提供稳定的 `data-dsh-mascot-action` 值。现有 `data-composer-input` 标记继续用于识别输入框事件。渲染该形象的宿主各自负责布局：侧栏缩放自己的字标外层，首屏保留自己的标记容器，形象本身不携带页面几何。动画仅作装饰且状态短暂，不写入 Session，也不影响模型输入。

组件规格覆盖输入框与动作反应、指针视线、待机动作和减少动态效果设置。各包 README 说明共用形象及其行为。
